# 从零开始：把 GTA6（Xbox Series 版）跑在 PC 上

这份教程写给**完全没接触过本项目的玩家**：从下载到进游戏、从设置到排错，一步步来。
不需要会编程、不需要自己编译。
This is a from-scratch guide for players new to the project: download → run → settings → troubleshooting.
An English digest is at the end.

> ⚠️ 先说明：本项目是**转译层**，不是游戏本体。仓库和发布包**不含任何游戏文件**。
> 你必须自己拥有 Xbox Series 版 GTA6 的转储（dump），即包含 `game_scarlett_master.exe` 的那个游戏文件夹。
> **No game files are provided.** Bring your own dump of the Xbox Series build.

---

## 0. 开始前的检查清单

| 项目 | 要求 | 怎么确认 |
| --- | --- | --- |
| 系统 | Windows 11（22H2+） | 设置 → 系统 → 关于 |
| 显卡 | NVIDIA RTX 20 / 30 / 40 / 50，**8 GB 显存起** | 任务管理器 → 性能 → GPU |
| 驱动 | NVIDIA 580 或更新 | NVIDIA 控制面板 → 帮助 → 系统信息 |
| 磁盘 | 游戏本体 200 GB 左右 + 本包 0.1 GB；建议再留 20 GB 余量 | 资源管理器 |
| 游戏 | 你自己的 Xbox Series 版 GTA6 v1.0.2.1 转储 | 文件夹里有 `game_scarlett_master.exe` |

> 显存 8 GB 是"能跑"的底线；6 GB 的卡会频繁爆显存（贴图缺失/卡死），不推荐。

---

## 1. 下载哪个包？

打开 [Releases](https://github.com/DKTTT/victory-nvidia-8gb/releases)，看你的显卡：

| 你的显卡 | 下载 | 理由 |
| --- | --- | --- |
| RTX 20 / 30 系（老 N 卡） | `GTA6-CN-8G-oldN-FSR-*.zip` | 默认 **AMD FSR 3 插帧 2X**，不需要第三方插件，最省事 |
| RTX 40 / 50 系（新 N 卡） | `GTA6-CN-8G-newN-FG-FSR-*.zip` | 默认 **NVIDIA DLSS 帧生成**（原生） |
| RTX 30 系想 3X～6X | 两个包都行，用包内 `启动-多倍插帧(DLSS-G).bat` | 走包内 `dlssg-sm86` 插件 |

两个包都约 **61 MB**，已经内置了所有运行库（NVIDIA Streamline/DLSS、AMD FSR、DLSS-G 插件），**不需要再下载任何东西**。

---

## 2. 解压和摆放

1. 把 zip 解压成**一个文件夹**（右键 → 全部解压），不要只把 `victory.exe` 拖出来。
   解压后应该能看到：`victory.exe`、`启动.bat`、`nvidia-sdk\`、`amd-sdk\`、`dlssg-sm86\` 等。
2. 推荐摆放方式（任选一种）：
   - **A（最简单）**：把整个解压文件夹**放进游戏目录**（和 `game_scarlett_master.exe` 同一个文件夹）。
   - **B**：解压文件夹放任意位置（比如 `D:\GTA6-CN`），第一次运行前用包里的 `设置游戏目录.bat` 选一次游戏目录。
   - **C**：把游戏文件夹直接**拖到 `启动.bat` 图标上**。

> 启动脚本会自动找游戏目录：本包所在目录 → `game-path.txt` 记录 → `VICTORY_GAME_DIR` → 各盘名字带 `GTA6` 的文件夹 → 常见路径。
> 实在找不到时会提示你用上面 A/B/C 的任意一种。

3. 杀毒软件可能误报 `victory.exe`（它是转译层），选择"允许/信任"或把它加入白名单。

---

## 3. 第一次启动

1. 双击 **`启动.bat`**（窗口标题带"GTA6 CN"）。
2. 会弹出一个命令行窗口，显示：
   - `游戏目录: ...`（确认找对了）
   - `Log: ...victory-nvidia-play-*.log`（日志路径）
   - `frame gen  GPU ... / DLSS UPSCALING ON / FRAME GEN ...`（启动提示，同时游戏画面顶部也会显示 30 秒）
3. 游戏窗口出现后：
   - 第一次启动会**编译着色器**，可能黑屏几十秒到几分钟，**不要急着关**。
   - 看到"选择账户"画面时，按 **A**（键盘 A 或回车）进入游戏。
4. 进游戏后按 **F1** 打开中文设置菜单（Esc 关闭）。

> 如果启动窗口一闪就没了，或游戏黑屏后退出：先看窗口里的"退出码"和日志最后几行，对照第 7 节。

---

## 4. 推荐设置（第一次进游戏就调这几项）

按 **F1** → 用 ↑↓ 选择、←→ 修改 → 选「**立即保存并重启**」→ 再进游戏。

| 菜单项 | 推荐值 | 说明 |
| --- | --- | --- |
| DLSS | 画质（8G 卡也可以试均衡） | 超分档位，画质优先 |
| 帧生成 | 2X | 老 N 卡走 FSR 2X；40/50 可试 3X/4X |
| 帧生成类型(重启) | 自动 | 有 DLSS 帧生成的卡会自动用 DLSS |
| 主机模式 | 系列 S（更快） | 默认就是；想画质好再切系列 X |
| 画面尺寸 | 1080p拉伸 | 比原生 1440p 流畅得多 |
| 纹理少 mip | 1 | 8G 显存的最佳平衡；爆显存再调 2/3 |
| 顶部帧率 | 开 | 方便观察帧数（卡顿可关） |

> 菜单里 `*` = 改了下一次启动生效；`即时` = 立即生效；`NOT SET` = 启动器没给默认值。

---

## 5. 怎么退出、存档在哪

- 正常退出游戏（游戏内菜单退出）即可，**不要直接强杀进程**。
- 存档位置（用 bat 启动时）：
  `E:\gta6\work\perf-data\7952987A`
  如果 bat 里配置的路径不存在，会回退到 `%LOCALAPPDATA%\victory\data\7952987A`。
- **重要**：直接双击 `victory.exe` 启动会用另一个存档目录，看起来像"存档丢了"——所以请始终用 bat 启动。
- 迁移/备份：把整个 `7952987A` 文件夹复制走即可。

## 5.5 预热（让进世界更顺）

两个预热脚本，都放在游戏文件夹里：

| 脚本 | 做什么 | 多久 |
|---|---|---|
| `预热.bat` | 编译着色器 + 预热管线 | 几分钟 |
| `预热-火力全开.bat` | 全核编译**全部**着色器 → **反复**预热**所有**管线 → 写入管线库 | 第一次可能几十分钟到几小时 |

`预热-火力全开.bat` 会**按你的 CPU 核心数自动分档**（低配/中配/高配/极高配）决定开多少线程和进程，
开始前还会**弹窗确认**：告诉你预计耗时、并提醒预热期间可能卡顿（会吃满 CPU），点「是」才开始。
所以别一边预热一边玩游戏。中途 Ctrl+C 不会白做，下次运行会接着做。

常用参数（可写在 bat 后面）：
- `-Fast` 快速模式：只做加载期用到的管线，几分钟（时间紧就先用这个）
- `-SkipShaders` 跳过着色器编译（已经编过一遍时）
- `-WarmLimit 100` 这一轮只做 100 条管线（试跑）
- `-FullRebuild` 连之前做过的管线也重做（更新构建/驱动后用）
- `-Yes` 跳过确认弹窗（自动化用）；`-NoGui` 不弹 GUI，只在控制台确认

预热用的是 `缓存` 目录，和 `启动.bat` 共用；预热完成后直接启动就生效。

## 6. 性能怎么调（按效果排序）

1. **帧生成**：最有效。老 N 卡 FSR 2X；新 N 卡/30 系用 DLSS-G 多倍。
2. **画面尺寸**：1080p 拉伸 → 1440p → 4K，逐级试。
3. **主机模式**：系列 S 比系列 X 快不少。
4. **纹理少 mip**：8G 卡 1；仍卡顿/贴图缺失就 2。
5. **关掉顶部帧率和 F3 面板**：这两项本身有开销。
6. 显存相关（`显存窗口`/`卡片步进`/`间接批次`）先用默认，不要乱动。

> 本层是 CPU 瓶颈（转译+提交），所以"降分辨率"收益没有"开插帧"大。
> 如果帧生成开了但画面很怪（重影/拖动条），先确认是 FSR 2X 而不是某个插件档位。

## 7. 常见问题（新手版）

| 现象 | 先做什么 |
| --- | --- |
| 启动窗口一闪就没 / 退出码 -2147483645 | `0x80000003`：游戏内部断言。先运行 `重置F1设置(卡崩时用).bat` 再启动；还不行看日志并反馈 |
| 退出码 -1073741819 | `0xC0000005` 访问冲突。附日志反馈 |
| 黑屏很久没反应 | 首次要编译着色器，等 2-3 分钟；再不行看日志最后几行 |
| 卡在"选择账户" | 按 **A** 或回车 |
| 帧生成显示"关" | 20/30 系需要 DLSS-G 插件包/FSR 运行库：确认整个文件夹都在，别只拷 exe；看启动提示写的"为什么不行" |
| 保存并重启后设置/帧生成丢了 | 更新到最新版（已修复）；重启后 F1 里再看一眼 |
| 存档"没了" | 你可能是直接双击 exe 启动的；用 bat |
| 找不到游戏文件夹 | 运行 `设置游戏目录.bat` 选一次，或把游戏文件夹拖到 `启动.bat` 上 |
| 游戏里贴图模糊/缺失、掉帧严重 | 纹理少 mip 调到 2；画面尺寸降一档；关顶部帧率/F3 |
| 电脑死机/驱动重置（TDR） | 降画质、更新驱动；检查机箱散热 |

日志位置：`%LOCALAPPDATA%\victory\logs\victory-nvidia-play-*.log`（窗口里也会打印路径）。
反馈问题时附上：显卡型号 + 驱动版本 + 日志最后 50 行 + 当时在做什么。

## 8. 名词小抄

| 名词 | 意思 |
| --- | --- |
| 转译层 | 把主机游戏的可执行文件"翻译"成 PC 能跑的程序（本项目） |
| DLSS | NVIDIA 超分辨率（画质/均衡/性能档） |
| 帧生成 / FG | 在两帧之间插一帧，让画面更流畅；FSR 3 = 2X，DLSS-G = 2X～6X |
| FSR | AMD 的超分/插帧技术（本项目用它给老 N 卡做 2X 插帧） |
| mip / MIP DROP | 纹理细节层级；少一级 = 更省显存、纹理稍糊 |
| XSS / 系列 S | Xbox Series S 主机配置，性能档，帧数更高 |

## English digest

**What you need.** Windows 11, an NVIDIA RTX 20/30/40/50 with 8 GB VRAM, a recent driver,
and your own dump of the Xbox Series build of GTA6 v1.0.2.1 (the folder with
`game_scarlett_master.exe`). No game files are distributed here.

**Download.** From Releases: `oldN-FSR` for RTX 20/30, `newN-FG-FSR` for RTX 40/50.
Both are ~61 MB and bundle every runtime; nothing else to download.

**Install.** Extract the whole folder. Put it inside the game folder (easiest), or use
`设置游戏目录.bat` to pick the game folder once, or drag the game folder onto `启动.bat`.
Start with the bat — do not double-click `victory.exe` (it uses a different save folder).

**First run.** The first start translates shaders and can take a while. Press **A** at the
account screen. Press **F1** for the Chinese settings menu.

**Suggested settings.** DLSS quality, frame generation 2x, Series S, 1080p upscaling,
texture mip drop 1, FPS line on.

**Exit codes.** `-2147483645` = `0x80000003`, the title asserted; `-1073741819` = `0xC0000005`,
an access violation. Run `重置F1设置(卡崩时用).bat` (reset F1 settings) first and attach the
log from `%LOCALAPPDATA%\victory\logs\` when reporting.
